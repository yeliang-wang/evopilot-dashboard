# Code of Conduct

EvoPilot Dashboard contributors, maintainers, and users are expected to keep project discussions professional, technical, and useful.

## Expected Behavior

- Be respectful and direct when discussing UX, API contracts, browser operation, and release risk.
- Focus feedback on user impact, evidence, tests, docs, and maintainability.
- Provide enough context for others to reproduce issues or evaluate proposals.
- Respect secrets, tenant data, repository access, and production evidence boundaries.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing secrets, credentials, private tenant data, or vulnerability details in public channels.
- Intentionally misleading API compatibility, release, security, or production-readiness claims.
- Repeatedly derailing technical discussions after maintainers ask to return to scope.

## Enforcement

Maintainers may edit or remove inappropriate comments, close discussions, restrict participation, or take other reasonable actions to protect the project and its users.

For security-sensitive issues, follow [SECURITY.md](SECURITY.md) instead of public discussion.
