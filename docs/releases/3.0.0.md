# EvoPilot Dashboard v3.0.0 Release Notes

EvoPilot Dashboard v3.0.0 is the EvoPilot v3 external Harness Catalog consumer compatibility release. It keeps Dashboard as a browser HTTP client while moving Harness lifecycle, evolution, approval, versioning, publication, and `CATALOG.md` maintenance to `evopilot-harness`.

## What Changed

- Converts Harness Hub / 专家市场 into a read-only surface for published Harness Catalogs.
- Displays Catalog id, compatibility, source types, available domain Harness experts, Harness versions, entry paths, and digests returned by EvoPilot.
- Removes Dashboard calls for Harness mount, scan, template match, template evolution, project harness profile generation, and project harness activation.
- Uses EvoPilot `POST /api/v1/goals` and `POST /api/v1/goals/{goalId}/plan` as the selectedHarness planning path.
- Treats `selectedHarness.yaml` as a goal-plan binding that must be reviewed before Alpha/Beta/RC/GA phase-plan approval.
- Keeps Dashboard from reading local Catalog folders or parsing `CATALOG.md` directly.

## Compatibility

- Compatible EvoPilot API: `v3.0.0` or later.
- Compatible Harness Catalog provider: `evopilot-harness v1.0.0` or later.
- API contract version: `v1`.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:3.0.0`.
- Node.js: 22 or later.
- Browser support: modern Chromium, Safari, and Firefox with ES module support.

## Install Paths

Run Dashboard from the tagged release:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v3.0.0/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Run as a cloud/container image:

```bash
docker run --rm -p 8080:8080 \
  -e EVOPILOT_API_BASE_URL=http://127.0.0.1:19876 \
  ghcr.io/yeliang-wang/evopilot-dashboard:3.0.0
```

## Operator Notes

Dashboard does not create or mutate Harness definitions in v3. If Harness Hub shows a missing or stale Catalog, publish a usable Harness with `evopilot-harness`, configure EvoPilot with `EVOPILOT_HARNESS_CATALOG_DIR` or `EVOPILOT_HARNESS_CATALOG_DIRS`, then regenerate the goal plan.

## Rollback

Rollback to `v2.5.0` or the previous image digest only with the matching EvoPilot API generation. After rollback, verify `/health`, login, Agent Console project intake, selectedHarness review, Harness Hub rendering, Evidence Drawer, and EvoPilot API `/api/v1/version`.
