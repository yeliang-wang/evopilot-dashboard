# EvoPilot Dashboard v2.4.0 Release Notes

EvoPilot Dashboard v2.4.0 is the browser compatibility release for EvoPilot v2.4.0 one-command Harness evolution. Existing login, Agent Console, LLM profile controls, Evidence Drawer, Harness Knowledge Factory, template auto-match, and release decision flows remain compatible.

## What Changed

- Adds Dashboard wiring for EvoPilot `POST /api/v1/harness/template-evolutions/evolve`.
- Changes the Harness Templates administrator action to submit a source project and goal to EvoPilot's server-governed one-command evolve workflow.
- Displays the server-returned review draft result, including auto-match projection, validation, source coverage, diff, and next action.
- Keeps source scanning, match selection, draft generation, validation, approval, publish, and impact analysis inside EvoPilot API.
- Updates mocked browser API fixtures and static contract coverage for `evopilot-harness-evolve-result/v1`.

## Compatibility

- Compatible EvoPilot API: `v2.4.0` or later.
- API contract version: `v1`.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:2.4.0`.
- Node.js: 22 or later.
- Browser support: modern Chromium, Safari, and Firefox with ES module support.

## Install Paths

Run Dashboard from the tagged release:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v2.4.0/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Run as a cloud/container image:

```bash
docker run --rm -p 8080:8080 \
  -e EVOPILOT_API_BASE_URL=http://127.0.0.1:19876 \
  ghcr.io/yeliang-wang/evopilot-dashboard:2.4.0
```

## Operator Notes

One-command Harness evolution is an administrator flow. The default action stops at review draft generation and does not approve or publish a template.

Stop before approval or publish until EvoPilot has shown source coverage, generated pack, validation, diff, changelog, redaction status, project impact, request ID, and next action.

Dashboard does not calculate match confidence or project impact locally. It renders EvoPilot's server projection and submits administrator source inputs to EvoPilot.
