# EvoPilot Dashboard v1.0.0 Release Notes

Release date: 2026-08-02

## Summary

EvoPilot Dashboard v1.0.0 is the public production baseline for the standalone Agent Console. It provides the browser path for project intake, `ProjectHarnessProfile.yaml` draft review, owner approval, goal loop execution, evidence inspection, blocker repair, and release decision review against EvoPilot API.

## Highlights

- Chat-first Agent Console v2 flow for ordinary users.
- YAML-like harness draft review before activation.
- Evidence Drawer for request IDs, profile digests, policy refs, blockers, `nextAction`, logs, and token usage.
- AI Agent docs for WorkBuddy-style browser operation.
- Self-hosting, release management, and open-source maturity docs.
- Apache-2.0 license alignment with EvoPilot.

## Compatibility

| Component | Compatible Version |
| --- | --- |
| EvoPilot API | 1.0.0 or compatible OpenAPI contract |
| Node.js | 22+ |
| Browser target | Chrome desktop |
| License | Apache-2.0 |

## Validation

```bash
npm run check
npm run smoke:console
git diff --check
```

Smoke requires a running EvoPilot API. Non-mutating smoke is preferred for production and shared environments.

## Known Limits

- Dashboard does not own server state and cannot replace EvoPilot CLI for low-level automation.
- Public community maturity depends on external users, release cadence, and contributor activity after publication.
