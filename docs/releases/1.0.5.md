# EvoPilot Dashboard v1.0.5 Release Notes

## Summary

EvoPilot Dashboard v1.0.5 is a GA visual-regression stability patch. It keeps the v1.0.4 browser test matrix and release-readiness scope, then stabilizes the mobile blocker screenshot baseline for CI production evidence.

v1.0.5 supersedes v1.0.4 for release and ECS production rollout because v1.0.4's tag-triggered Visual Regression workflow failed on cross-platform mobile full-page screenshot height variance.

## What Changed

- Stabilized `tests/visual/agent-console-visual.spec.ts` by using a viewport screenshot for the mobile blocker state.
- Updated the 390px blocker-state visual baseline so Ubuntu runners and local Chrome agree on the asserted image dimensions.
- Kept the browser E2E, visual regression, live E2E, PR artifact, and immutable release artifact workflows introduced in v1.0.4.
- Updated release-facing docs so v1.0.5 is the production rollout target.

## Who Should Upgrade

Upgrade if you operate Dashboard production releases, review visual-regression evidence, or deploy Dashboard to ECS from immutable release image metadata.

## Compatibility

- Compatible EvoPilot API: v1.0.7 or later.
- API contract version: v1.
- No Dashboard data migration is required.
- Live E2E is non-mutating login smoke unless an administrator explicitly approves a disposable project and target.

## Validation

- `npm run check`
- `npm run test:browser`
- `npm run test:e2e:live` skipped without live API URL and credentials
- `npm run release:artifact`
- `npm run verify:release-artifact`
- `git diff --check`

## Deployment Notes

For immutable ECS rollout, deploy the image reference recorded in `evopilot-dashboard-1.0.5-image-metadata.json`:

```bash
export EVOPILOT_DASHBOARD_IMAGE='ghcr.io/yeliang-wang/evopilot-dashboard@sha256:<digest>'
docker compose -p evopilot-dashboard --env-file .env -f deploy/ecs/compose.immutable.yaml up -d --no-build
```

Keep the production `EVOPILOT_API_BASE_URL`, network, port, and reverse-proxy configuration under operator control.

## Rollback

Rollback to the previous Dashboard image digest or release tag, then verify Dashboard `/health`, the public HTTP entrypoint, Playwright smoke where applicable, and EvoPilot API compatibility.
