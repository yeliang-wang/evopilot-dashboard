# EvoPilot Dashboard v1.0.2 Release Notes

## Summary

EvoPilot Dashboard v1.0.2 is a GA artifact-publishing patch for the standalone Agent Console. It keeps the v1.0.0 browser product contract and adds immutable release artifacts for operators who need to deploy a pinned image digest instead of building from a production checkout.

## What Changed

- GitHub tag publishing now builds and uploads release artifacts:
  - `evopilot-dashboard-1.0.2-source.tar.gz`
  - `evopilot-dashboard-1.0.2-sbom.spdx.json`
  - `evopilot-dashboard-1.0.2-provenance.json`
  - `evopilot-dashboard-1.0.2-image-metadata.json`
  - `SHA256SUMS`
- The source archive includes the built `dist/` assets for reproducible static inspection.
- The release workflow publishes the Dashboard image to GHCR and records its immutable digest in release metadata.
- `deploy/ecs/compose.immutable.yaml` supports ECS deployment by pinned image digest.

## Who Should Upgrade

Upgrade if production rollout evidence must prove the exact Dashboard artifact or image digest running on ECS. Operators already on v1.0.1 can keep the same browser behavior and move only the deployment source from a Git checkout to an immutable image reference.

## Compatibility

- Compatible EvoPilot API: v1.0.4 or later.
- API contract version: v1.
- No Dashboard data migration is required.

## Validation

- `npm run check`
- `npm run release:artifact`
- `npm run verify:release-artifact`
- GitHub Release artifact upload through `.github/workflows/release-artifacts.yml`

## Deployment Notes

For immutable ECS rollout, deploy the image reference recorded in `evopilot-dashboard-1.0.2-image-metadata.json`:

```bash
export EVOPILOT_DASHBOARD_IMAGE='ghcr.io/yeliang-wang/evopilot-dashboard@sha256:<digest>'
docker compose -f deploy/ecs/compose.immutable.yaml up -d
```

Keep the production `EVOPILOT_API_BASE_URL`, network, port, and reverse-proxy configuration under operator control.

`v1.0.3` supersedes this deployment command with explicit compose project and env-file flags for ECS production rollout.

## Rollback

Rollback to the previous Dashboard image digest or release tag, then verify Dashboard `/health`, the public HTTP entrypoint, and EvoPilot API compatibility.
