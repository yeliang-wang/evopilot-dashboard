# EvoPilot Dashboard v2.0.0 Release Notes

EvoPilot Dashboard v2.0.0 is the browser compatibility release for EvoPilot v2.0.0 domain-first HarnessTemplate support. Existing login, Agent Console, management pages, LLM profile controls, evidence drawer, and release decision flows remain compatible.

## What Changed

- Shows the server-returned harness layer for generated `ProjectHarnessProfile` drafts.
- Shows domain template metadata such as `domain`, `compatibilityProfiles`, `architectureProfiles`, and `runtimeProfiles`.
- Shows the reference boundary returned by EvoPilot, including the database rule that PostgreSQL/MySQL are compatibility references or differential oracles rather than the product being evolved.
- Updates demo mode and mocked browser API fixtures to `database-product-harness@2.0.0`.
- Updates version metadata, installer defaults, Cloud deployment docs, distribution docs, governance checks, and release pointers to `2.0.0`.

## Compatibility

- Compatible EvoPilot API: `v2.0.0` or later.
- API contract version: `v1`.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:2.0.0`.
- Node.js: 22 or later.

## Install

Run the release image:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v2.0.0/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Or run a container directly:

```bash
npm run dashboard:run -- \
  --image ghcr.io/yeliang-wang/evopilot-dashboard:2.0.0 \
  --api-url http://127.0.0.1:19876 \
  --start
```

## Operator Notes

Dashboard does not choose or calculate templates. It displays the `ProjectHarnessProfile` and generation evidence returned by EvoPilot. If the Dashboard does not show a domain layer for a project expected to use a v2 domain template, inspect the EvoPilot response `generatedBy.evidence[]`, `sourceContent.runtime`, and `metadata.templateDomain`.

## Rollback

Rollback to `v1.0.14` or the previous image digest, then verify `/health`, login, Agent Console project intake, harness draft review, Evidence Drawer, and EvoPilot API `/api/v1/version`.
