# EvoPilot Dashboard v1.0.9 Release Notes

EvoPilot Dashboard v1.0.9 is a GA project LLM usage visibility patch. It keeps the v1.0.8 Agent Console module boundary and adds a Workspaces-page view for EvoPilot's connected-project token usage projection.

## What Changed

- Added `接入项目 LLM 用量追踪` to the Workspaces page.
- Added workspace summary cards for total tokens, connected projects with LLM usage, LLM provider/model/profile combinations, and top token project.
- Added a project/LLM table with project id/name, actual provider/model/profile, calls, input/output/total tokens, workspace share, latest loop token total, latest loop id/status, and request id.
- Extended `src/api.ts` to call `GET /api/v1/workspaces/{workspaceId}/usage` and `GET /api/v1/projects/{projectId}/usage`.
- Updated static contracts, API docs, and AI-agent expected states for the new server projection.

## Compatibility

- Compatible EvoPilot API: `v1.1.6` or later for project/workspace LLM usage projections.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:1.0.9`.
- Node.js: 22 or later for repository validation and local development.
- Docker Compose: v2 for generated container run directories.

## Deploy Paths

Run from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v1.0.9/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Deploy the image on a cloud container service:

```bash
gcloud run deploy evopilot-dashboard \
  --image ghcr.io/yeliang-wang/evopilot-dashboard:1.0.9 \
  --port 8080 \
  --set-env-vars EVOPILOT_API_BASE_URL=https://evopilot.example.com
```

Build static assets:

```bash
EVOPILOT_API_BASE_URL=https://evopilot.example.com npm run build
```

## Operator Notes

Dashboard remains a browser HTTP client. EvoPilot API remains the system of record for authentication, tenant/workspace scope, projects, harness profiles, loops, evidence, audit, release decisions, credentials, and token totals.

The new Workspaces usage panel displays server projections. It should not be treated as an LLMOps quota-window dashboard, and browser code must not calculate project or workspace token totals locally.

## Rollback
