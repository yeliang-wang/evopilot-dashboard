# EvoPilot Dashboard v1.0.6 Release Notes

EvoPilot Dashboard v1.0.6 is a GA distribution-expansion patch. It keeps the v1.0.5 visual-regression stability baseline, then adds a standalone container runner and tagged installer so operators can run the browser surface without cloning and hand-wiring deployment files.

## What Changed

- Added `npm run dashboard:run` to generate a Docker Compose run directory for Dashboard connected to an EvoPilot API server, including optional external Docker network binding.
- Added tagged `install.sh` for `curl -fsSL ... | bash` bootstrap from GitHub Releases.
- Added `npm run verify:distribution` and included it in `npm run check`.
- Added release artifact packaging for `install.sh`.
- Updated README, distribution docs, self-hosting docs, readiness, maturity, changelog, and release-management docs for the new install path.

## Compatibility

- Compatible EvoPilot API: `v1.0.8` or later.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:1.0.6`.
- Node.js: 22 or later for repository validation and local development.
- Docker Compose: v2 for generated container run directories.

## Install Paths

Run from a source checkout:

```bash
npm run dashboard:run -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

For same-network service discovery:

```bash
npm run dashboard:run -- --api-url http://evopilot-server:19876 --network evopilot_default --dir evopilot-dashboard-run
```

Run from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v1.0.6/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Start the generated runtime:

```bash
cd evopilot-dashboard-run
docker compose up -d
./verify.sh
```

## Operator Notes

Dashboard remains an HTTP browser client. EvoPilot API remains the system of record for authentication, tenant/workspace scope, projects, harness profiles, loops, evidence, audit, release decisions, and credentials.

Desktop app and hosted Cloud trial remain outside the published Dashboard surface for this release.

## Rollback

Rollback to `v1.0.5` or the previous image digest, then verify `/health`, `/api/v1/summary`, login, Agent Console project intake, evidence drawer, and release decision rendering.
