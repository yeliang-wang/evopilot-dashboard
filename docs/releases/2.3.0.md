# EvoPilot Dashboard v2.3.0 Release Notes

EvoPilot Dashboard v2.3.0 is the browser compatibility release for EvoPilot v2.3.0 HarnessTemplate auto-match contracts. Existing login, Agent Console, LLM profile controls, Evidence Drawer, Harness Knowledge Factory, and release decision flows remain compatible.

## What Changed

- Adds a template match preview action to the Harness Templates evolution dialog.
- Shows server-returned match decision, confidence, base template, target template, target domain, and candidate count before creating a run.
- Submits `autoMatch: true` when creating `HarnessTemplateEvolution` runs from the Dashboard.
- Keeps match scoring, source digesting, candidate selection, target version choice, approval, publish, and impact analysis inside EvoPilot API.
- Updates demo mode and mocked browser API fixtures for distributed-cache auto-match reports.

## Compatibility

- Compatible EvoPilot API: `v2.3.0` or later.
- API contract version: `v1`.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:2.3.0`.
- Node.js: 22 or later.
- Browser support: modern Chromium, Safari, and Firefox with ES module support.

## Install Paths

Run Dashboard from the tagged release:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v2.3.0/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Run as a cloud/container image:

```bash
docker run --rm -p 8080:8080 \
  -e EVOPILOT_API_BASE_URL=http://127.0.0.1:19876 \
  ghcr.io/yeliang-wang/evopilot-dashboard:2.3.0
```

## Operator Notes

Template match preview is an administrator flow. Stop before approval/publish until EvoPilot has shown source coverage, match report, generated pack, validation, diff, changelog, redaction status, project impact, request ID, and next action.

Dashboard does not calculate match confidence or project impact locally. It renders EvoPilot's server projection and submits administrator source inputs to EvoPilot.

## Rollback

Rollback to `v2.2.0` or the previous image digest, then verify `/health`, login, Agent Console project intake, harness draft review, Harness Templates projection, template match preview, Evidence Drawer, and EvoPilot API `/api/v1/version`.
