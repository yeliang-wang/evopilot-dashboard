# EvoPilot Dashboard v2.1.0 Release Notes

EvoPilot Dashboard v2.1.0 is the browser compatibility release for EvoPilot v2.1.0 domain Harness execution contracts. Existing login, Agent Console, management pages, LLM profile controls, Evidence Drawer, and release decision flows remain compatible.

## What Changed

- Shows domain required actions returned by EvoPilot-generated `ProjectHarnessProfile` drafts.
- Shows domain evidence adapters that must produce Beta/RC/GA evidence.
- Shows domain release blockers that make missing evidence visible before activation or release decisions.
- Shows repository probe status and missing module boundaries for database and gateway domain Harness drafts.
- Updates demo mode and mocked browser API fixtures to `database-product-harness@2.1.0`.
- Updates version metadata, installer defaults, Cloud deployment docs, distribution docs, governance checks, and release pointers to `2.1.0`.

## Compatibility

- Compatible EvoPilot API: `v2.1.0` or later.
- API contract version: `v1`.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:2.1.0`.
- Node.js: 22 or later.
- Browser support: modern Chromium, Safari, and Firefox with ES module support.

## Install Paths

Run Dashboard from the tagged release:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v2.1.0/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Run as a cloud/container image:

```bash
docker run --rm -p 8080:8080 \
  -e EVOPILOT_API_BASE_URL=http://127.0.0.1:19876 \
  ghcr.io/yeliang-wang/evopilot-dashboard:2.1.0
```

## Operator Notes

Dashboard does not choose or calculate templates. It displays the `ProjectHarnessProfile` and generation evidence returned by EvoPilot. If required actions, evidence adapters, release blockers, or repo-probe fields are missing for a project expected to use a v2.1 domain template, inspect the EvoPilot response `sourceContent.validation`, `sourceContent.evidence`, `sourceContent.rules`, and `sourceContent.metadata.repoProbe`.

## Rollback

Rollback to `v2.0.0` or the previous image digest, then verify `/health`, login, Agent Console project intake, harness draft review, Evidence Drawer, and EvoPilot API `/api/v1/version`.
