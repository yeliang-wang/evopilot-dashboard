# EvoPilot Dashboard v1.0.4 Release Notes

## Summary

EvoPilot Dashboard v1.0.4 is a GA browser test-matrix patch. It keeps the v1.0.0 Agent Console product contract and v1.0.3 immutable deployment path, then adds browser E2E, visual regression, live E2E boundaries, PR artifacts, and mobile layout hardening.

## What Changed

- Added `npm run test:e2e:mock` for Agent Console browser flow coverage against an EvoPilot-shaped mocked API.
- Added `npm run test:visual` for stable owner review, blocker repair, and release decision screenshot baselines.
- Added `npm run test:browser` as the combined mock browser E2E and visual regression matrix.
- Added `npm run test:e2e:live` as an opt-in login smoke for real or approved disposable EvoPilot APIs.
- Added PR artifact workflow uploads for Playwright reports, test results, release artifacts, and verification output.
- Fixed mobile layout constraints so the console remains operable at 390px viewport width.
- Added the Dashboard operations test matrix and updated release-management and smoke-test docs.

## Who Should Upgrade

Upgrade if you review Dashboard releases, operate browser-based Agent Console flows, or deploy Dashboard to ECS production and need browser, visual, and PR artifact evidence before rollout.

## Compatibility

- Compatible EvoPilot API: v1.0.7 or later.
- API contract version: v1.
- No Dashboard data migration is required.
- Live E2E is non-mutating login smoke unless an administrator explicitly approves a disposable project and target.

## Validation

- `npm run check`
- `npm run test:browser`
- `npm run test:e2e:live` skipped without live API URL and credentials
- `npm run release:artifact`
- `npm run verify:release-artifact`
- `git diff --check`

## Deployment Notes

For immutable ECS rollout, deploy the image reference recorded in `evopilot-dashboard-1.0.4-image-metadata.json`:

```bash
export EVOPILOT_DASHBOARD_IMAGE='ghcr.io/yeliang-wang/evopilot-dashboard@sha256:<digest>'
docker compose -p evopilot-dashboard --env-file .env -f deploy/ecs/compose.immutable.yaml up -d --no-build
```

Keep the production `EVOPILOT_API_BASE_URL`, network, port, and reverse-proxy configuration under operator control.

## Rollback

Rollback to the previous Dashboard image digest or release tag, then verify Dashboard `/health`, the public HTTP entrypoint, Playwright smoke where applicable, and EvoPilot API compatibility.
