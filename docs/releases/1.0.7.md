# EvoPilot Dashboard v1.0.7 Release Notes

EvoPilot Dashboard v1.0.7 is a GA cloud-deployment entrypoint patch. It keeps the v1.0.6 container runner and tagged installer surface, then adds an operator-owned cloud deployment runbook and validates it as a release artifact.

## What Changed

- Added `docs/deployment/cloud.md` for Cloud Run, managed container services, and static hosting.
- Added `evopilot-dashboard-<version>-cloud-runbook.md` to release artifacts.
- Added distribution and release-artifact verification for cloud runbook image tag pinning and `EVOPILOT_API_BASE_URL` configuration.
- Updated README, distribution, self-hosting, getting started, release management, open-source readiness, and maturity docs for the cloud deployment entrypoint.

## Compatibility

- Compatible EvoPilot API: `v1.0.9` or later.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:1.0.7`.
- Node.js: 22 or later for repository validation and local development.
- Docker Compose: v2 for generated container run directories.

## Deploy Paths

Run from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v1.0.7/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Deploy the image on a cloud container service:

```bash
gcloud run deploy evopilot-dashboard \
  --image ghcr.io/yeliang-wang/evopilot-dashboard:1.0.7 \
  --port 8080 \
  --set-env-vars EVOPILOT_API_BASE_URL=https://evopilot.example.com
```

Build static assets:

```bash
EVOPILOT_API_BASE_URL=https://evopilot.example.com npm run build
```

## Validation

- `npm run check`
- `npm run verify:distribution`
- `npm run release:artifact`
- `npm run verify:release-artifact`
- `git diff --check`

## Operator Notes

Dashboard remains an HTTP browser client. EvoPilot API remains the system of record for authentication, tenant/workspace scope, projects, harness profiles, loops, evidence, audit, release decisions, and credentials.

Cloud deployment in this release means operator-owned cloud infrastructure. Hosted Dashboard Cloud trial and signed desktop app remain outside the published Dashboard surface.

## Rollback

Rollback to `v1.0.6` or the previous image digest, then verify `/health`, `/api/v1/summary`, login, Agent Console project intake, evidence drawer, and release decision rendering.
