# EvoPilot Dashboard v2.5.0 Release Notes

EvoPilot Dashboard v2.5.0 is the Harness Hub / 专家市场 compatibility release for EvoPilot v2.5.0 external Harness Catalog mounts. Existing login, Agent Console, LLM profile controls, Evidence Drawer, project harness review, one-command Harness evolution, and release decision flows remain compatible.

## What Changed

- Renames the visible administration entry from Harness Templates to Harness Hub.
- Adds Catalog mount visibility from EvoPilot `GET /api/v1/harness/catalogs`.
- Adds a Catalog mount dialog that submits `POST /api/v1/harness/catalogs` to EvoPilot.
- Adds Catalog scan actions through `POST /api/v1/harness/catalogs/{catalogId}/scan`.
- Adds 专家/Harness/连接器 tabs so administrators can distinguish domain expert assets, available Harness definitions, and source connectors for Harness evolution.
- Keeps browser behavior server-governed: Dashboard does not read local Catalog folders or parse `CATALOG.md` directly.
- Updates mocked browser API fixtures and static contract coverage for Harness Catalog projections.

## Compatibility

- Compatible EvoPilot API: `v2.5.0` or later.
- API contract version: `v1`.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:2.5.0`.
- Node.js: 22 or later.
- Browser support: modern Chromium, Safari, and Firefox with ES module support.

## Install Paths

Run Dashboard from the tagged release:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v2.5.0/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Run as a cloud/container image:

```bash
docker run --rm -p 8080:8080 \
  -e EVOPILOT_API_BASE_URL=http://127.0.0.1:19876 \
  ghcr.io/yeliang-wang/evopilot-dashboard:2.5.0
```

## Operator Notes

Harness Hub is an administrator flow. The Catalog source path is interpreted by EvoPilot server, not by the browser. Stop before approving or publishing a HarnessTemplate evolution until EvoPilot has shown source coverage, generated pack, validation, diff, changelog, redaction status, project impact, request ID, and next action.

## Rollback

Rollback to `v2.4.0` or the previous image digest, then verify `/health`, login, Agent Console project intake, harness draft review, Harness Hub projection, Catalog mount/list/scan rendering, one-command evolve review draft rendering, Evidence Drawer, and EvoPilot API `/api/v1/version`.
