# EvoPilot Dashboard v3.1.2 Release Notes

EvoPilot Dashboard v3.1.2 is the ECS immutable deployment patch for the independent `evopilot-harness` Hub iframe boundary.

## What Changed

- Passed `EVOPILOT_HARNESS_HUB_URL` through `deploy/ecs/compose.immutable.yaml`.
- Preserved the v3.1.1 Compose fix for `compose.yaml` and `compose.production.yaml`.
- Kept Harness management, evolution, approval, publication, Hub UI, and CLI ownership in `evopilot-harness`.

## Compatibility

- Compatible EvoPilot API: `v3.0.0` or later.
- Compatible Harness Hub provider: `evopilot-harness v1.1.0` or later.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:3.1.2`.
- Node.js: 22 or later.

## ECS Configuration

For digest-based deployment, set:

```bash
EVOPILOT_DASHBOARD_IMAGE=ghcr.io/yeliang-wang/evopilot-dashboard@sha256:<digest>
EVOPILOT_HARNESS_HUB_URL=http://8.153.72.80:4176
```

The Dashboard serves this value through `/config.js`; the Harness Hub menu embeds the independent `evopilot-harness` UI in the right-side iframe.
