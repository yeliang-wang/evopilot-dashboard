# EvoPilot Dashboard v1.0.11 Release Notes

EvoPilot Dashboard v1.0.11 is a GA production UI interaction release for the management pages. It keeps the Agent Console and left navigation unchanged while moving create/edit and evidence-detail flows into modal dialogs.

## What Changed

- Reworked Tenants, Workspaces, Users, and Harness Templates so the main page is a full-width live projection list with top-level and row-level actions.
- Replaced persistent right-side management forms with centered modal dialogs for tenant upsert, workspace creation, scoped user create/update, and HarnessTemplateEvolution draft creation.
- Moved Audit evidence review into a row/detail modal that shows the selected audit event fields, request IDs when returned, and last Dashboard action evidence.
- Kept the Workspaces project LLM usage panel on the main Workspaces page so project, provider/model/profile, loop token totals, and request IDs remain visible before opening any dialog.
- Aligned Tenants UI copy and submit body with the real EvoPilot tenant upsert API. Workspace and user setup remain separate EvoPilot API operations.
- Added responsive modal and table styling so desktop and mobile layouts keep the fixed left menu, readable lists, and no persistent right-side form column.

## Compatibility

- Compatible EvoPilot API: `v1.1.6` or later for project/workspace LLM usage projections and current admin routes.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:1.0.11`.
- Node.js: 22 or later for repository validation and local development.
- Docker Compose: v2 for generated container run directories.

## Deploy Paths

Run from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v1.0.11/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Deploy the image on a cloud container service:

```bash
gcloud run deploy evopilot-dashboard \
  --image ghcr.io/yeliang-wang/evopilot-dashboard:1.0.11 \
  --port 8080 \
  --set-env-vars EVOPILOT_API_BASE_URL=https://evopilot.example.com
```

Build static assets:

```bash
EVOPILOT_API_BASE_URL=https://evopilot.example.com npm run build
```

## Operator Notes

Dashboard remains a browser HTTP client. EvoPilot API remains the system of record for authentication, tenant/workspace scope, projects, harness profiles, loops, evidence, audit, release decisions, credentials, and token totals.

Workspace edit opens a prefilled dialog but does not submit a fake save because the current EvoPilot API does not expose workspace PATCH. Tenant upsert, workspace create, user create/update, and template evolution creation continue to use real EvoPilot API calls.
