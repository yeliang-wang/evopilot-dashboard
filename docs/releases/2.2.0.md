# EvoPilot Dashboard v2.2.0 Release Notes

EvoPilot Dashboard v2.2.0 is the browser compatibility release for EvoPilot v2.2.0 Harness Knowledge Factory contracts. Existing login, Agent Console, LLM profile controls, Evidence Drawer, and release decision flows remain compatible.

## What Changed

- Added a Harness Knowledge Factory table to the Harness Templates page.
- Shows `sourceTypes`, `domainSignals`, and `gapClassifications` returned by EvoPilot template evolution projections.
- Adds a create dialog for `HarnessTemplateEvolution` sources including historical projects, project corpora, production logs, EvoPilot history, attachments, repositories, existing templates, runtime evidence, and administrator notes.
- Keeps file extraction, production-log redaction, snapshots, LLM draft generation, approval, publish, and impact analysis inside EvoPilot API.
- Updates demo mode and mocked browser API fixtures to `database-product-harness@2.2.0`.

## Compatibility

- Compatible EvoPilot API: `v2.2.0` or later.
- API contract version: `v1`.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:2.2.0`.
- Node.js: 22 or later.
- Browser support: modern Chromium, Safari, and Firefox with ES module support.

## Install Paths

Run Dashboard from the tagged release:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v2.2.0/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Run as a cloud/container image:

```bash
docker run --rm -p 8080:8080 \
  -e EVOPILOT_API_BASE_URL=http://127.0.0.1:19876 \
  ghcr.io/yeliang-wang/evopilot-dashboard:2.2.0
```

## Operator Notes

Harness Knowledge Factory is an administrator flow. Stop before approval/publish until EvoPilot has shown source coverage, generated pack, validation, diff, changelog, redaction status, project impact, request ID, and next action.

Dashboard does not calculate project impact or classify gaps locally. It renders the server projection and submits administrator source inputs to EvoPilot.

## Rollback

Rollback to `v2.1.0` or the previous image digest, then verify `/health`, login, Agent Console project intake, harness draft review, Harness Templates projection, Evidence Drawer, and EvoPilot API `/api/v1/version`.
