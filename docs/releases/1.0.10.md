# EvoPilot Dashboard v1.0.10 Release Notes

EvoPilot Dashboard v1.0.10 is a GA production rendering fix for the Workspaces project LLM usage panel. It keeps the v1.0.9 usage surface and makes it resilient when unrelated production projections are slow or unavailable.

## What Changed

- Fixed Workspaces usage rendering so `GET /api/v1/workspaces/{workspaceId}/usage` can populate the page even when a non-critical projection such as audit is slow.
- Added per-request Dashboard API timeouts and all-settled snapshot aggregation.
- Added progressive snapshot writes so successful projections become visible as they return.
- Gave usage projections a longer timeout window than ordinary control-plane list calls.
- Limited the Workspaces usage table to the top five token rows and tightened long loop/request ID rendering for real production identifiers.
- Updated static contracts so timeout, all-settled aggregation, and progressive snapshot handling remain part of the Dashboard API boundary.

## Compatibility

- Compatible EvoPilot API: `v1.1.6` or later for project/workspace LLM usage projections.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:1.0.10`.
- Node.js: 22 or later for repository validation and local development.
- Docker Compose: v2 for generated container run directories.

## Deploy Paths

Run from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v1.0.10/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Deploy the image on a cloud container service:

```bash
gcloud run deploy evopilot-dashboard \
  --image ghcr.io/yeliang-wang/evopilot-dashboard:1.0.10 \
  --port 8080 \
  --set-env-vars EVOPILOT_API_BASE_URL=https://evopilot.example.com
```

Build static assets:

```bash
EVOPILOT_API_BASE_URL=https://evopilot.example.com npm run build
```

## Operator Notes

Dashboard remains a browser HTTP client. EvoPilot API remains the system of record for authentication, tenant/workspace scope, projects, harness profiles, loops, evidence, audit, release decisions, credentials, and token totals.

This release does not redefine usage as an LLMOps quota-window dashboard. It fixes the production rendering path for EvoPilot's connected-project token usage projection.
