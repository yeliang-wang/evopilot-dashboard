# EvoPilot Dashboard v1.0.1 Release Notes

Release date: 2026-08-02

## Summary

EvoPilot Dashboard v1.0.1 is a GA publication-hardening patch for the standalone Agent Console. It keeps the v1.0.0 product contract and publishes the latest README screenshot, version metadata, and release evidence as the current public Dashboard baseline.

## Highlights

- README release badge and release notes point to v1.0.1.
- Package metadata is aligned to `1.0.1`.
- The latest Agent Console screenshot is included in the public README state.
- The browser product boundary remains unchanged: Dashboard is a standalone HTTP client over EvoPilot API.

## Compatibility

| Component | Compatible Version |
| --- | --- |
| EvoPilot API | 1.0.0 or compatible OpenAPI contract |
| Node.js | 22+ |
| Browser target | Chrome desktop |
| License | Apache-2.0 |

## Validation

```bash
npm run check
npm run smoke:console
git diff --check
```

Smoke requires a running EvoPilot API. Non-mutating smoke is preferred for production and shared environments.

## Known Limits

- Dashboard does not own server state and cannot replace EvoPilot CLI for low-level automation.
- Public community maturity depends on external users, release cadence, and contributor activity after publication.
