# EvoPilot Dashboard v3.1.1 Release Notes

EvoPilot Dashboard v3.1.1 is a production Compose patch for the independent `evopilot-harness` Hub iframe boundary introduced in v3.1.0.

## What Changed

- Passed `EVOPILOT_HARNESS_HUB_URL` through `compose.yaml` and `compose.production.yaml`.
- Kept the Dashboard-owned surface limited to EvoPilot project intake, selectedHarness review, loop execution, evidence, release decisions, and the iframe host.
- Kept Harness management, evolution, approval, publication, Hub UI, and CLI ownership in `evopilot-harness`.

## Compatibility

- Compatible EvoPilot API: `v3.0.0` or later.
- Compatible Harness Hub provider: `evopilot-harness v1.1.0` or later.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:3.1.1`.
- Node.js: 22 or later.

## ECS / Self-Hosted Configuration

Set the Harness Hub URL to a browser-reachable address before starting Dashboard:

```bash
EVOPILOT_HARNESS_HUB_URL=http://8.153.72.80:4176
```

The value is served through `/config.js` as `window.EVOPILOT_DASHBOARD_CONFIG.harnessHubUrl`, and the Dashboard Harness Hub page embeds that URL in the right-side iframe.
