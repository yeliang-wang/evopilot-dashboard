# EvoPilot Dashboard v3.1.0 Release Notes

EvoPilot Dashboard v3.1.0 is the embedded independent `evopilot-harness` Hub compatibility release. Dashboard remains the EvoPilot browser console for project intake, selectedHarness review, loop execution, evidence, and release decisions.

## What Changed

- Replaced the Dashboard-owned Harness Hub Catalog tables with an iframe container that loads the independent `evopilot-harness` Hub.
- Added runtime configuration `window.EVOPILOT_DASHBOARD_CONFIG.harnessHubUrl`.
- Added container runtime configuration `EVOPILOT_HARNESS_HUB_URL` for the iframe URL exposed through `/config.js`.
- Removed Dashboard active dependencies on EvoPilot Harness Catalog list/inspect APIs from the Harness Hub page and smoke tests.
- Kept Agent Console `selectedHarness.yaml` review as part of EvoPilot goal-plan approval.

## Compatibility

- Compatible EvoPilot API: `v3.0.0` or later.
- Compatible Harness Hub provider: `evopilot-harness v1.1.0` or later.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:3.1.0`.
- Node.js: 22 or later.

## Install Paths

Run Dashboard from the tagged release:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v3.1.0/install.sh | bash -s -- \
  --api-url http://127.0.0.1:19876 \
  --harness-hub-url http://127.0.0.1:4176 \
  --dir evopilot-dashboard-run
```

Run as a cloud/container image:

```bash
docker run --rm -p 8080:8080 \
  -e EVOPILOT_API_BASE_URL=http://127.0.0.1:19876 \
  -e EVOPILOT_HARNESS_HUB_URL=http://127.0.0.1:4176 \
  ghcr.io/yeliang-wang/evopilot-dashboard:3.1.0
```

## Operator Notes

Dashboard does not create, approve, publish, evolve, or store Harness definitions. Start `evopilot-harness hub serve` or deploy the `evopilot-harness` Hub separately, then point Dashboard `harnessHubUrl` at that Hub. EvoPilot goal planning still reads published Catalog directories configured on the EvoPilot server.

## Rollback

Rollback to `v3.0.0` or the previous image digest if iframe embedding introduces a Dashboard issue. Verify `/health`, login, Agent Console project intake, selectedHarness review, Harness Hub iframe rendering, Evidence Drawer, and EvoPilot API `/api/v1/version`.
