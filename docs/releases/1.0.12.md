# EvoPilot Dashboard v1.0.12 Release Notes

EvoPilot Dashboard v1.0.12 updates the Agent Console project intake surface for EvoPilot v1.1.7. It adds delivery chain selection for GitHub-native, GitLab-native, and GitHub source + GitLab CI bridge projects while keeping the left navigation, management modal pages, and governed review flow intact.

## What Changed

- Added delivery chain buttons to Agent Console intake:
  - GitHub source + GitHub Actions
  - GitLab source + GitLab CI
  - GitHub source + GitLab CI Bridge
- Added bridge fields for GitLab base URL, GitLab CI project, GitLab ref, source tokenRef, DevOps tokenRef, required stage, and required job.
- Updated Dashboard onboarding payloads to submit EvoPilot's server contract: `sourceMode=external-source`, `workflowProvider=gitlab`, `workflowRepository`, `workflowProjectId`, `gitlabRef`, and bridge metadata.
- Updated Evidence Drawer to show project, source system, CI/Loop executor, workflow repository, LLM profile, source tokenRef, and DevOps tokenRef evidence.
- Split the Composer into a dedicated component module so Agent Console remains within the repository's component-size guardrails.
- Added static contract checks for the bridge UI and payload fields.

## Compatibility

- Compatible EvoPilot API: `v1.1.7` or later for GitHub source + GitLab CI bridge readiness and delivery execution.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:1.0.12`.
- Node.js: 22 or later for repository validation and local development.
- Docker Compose: v2 for generated container run directories.

## Deploy Paths

Run from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v1.0.12/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Deploy the image on a cloud container service:

```bash
gcloud run deploy evopilot-dashboard \
  --image ghcr.io/yeliang-wang/evopilot-dashboard:1.0.12 \
  --port 8080 \
  --set-env-vars EVOPILOT_API_BASE_URL=https://evopilot.example.com
```

## Operator Notes

Dashboard remains a browser HTTP client. EvoPilot API remains the system of record for source credentials, GitLab CI execution credentials, project DevOps readiness, harness profiles, loops, evidence, audit, release decisions, and token usage.

Do not paste raw GitHub or GitLab tokens into Dashboard screenshots or docs. Use server-side `tokenRef` and `devopsTokenRef`.
