# EvoPilot Dashboard v1.0.14 Release Notes

EvoPilot Dashboard v1.0.14 closes the production visual-regression gate for the LLM Profiles UI released in v1.0.13. The browser functionality remains the same: workspace/user LLM profile registration, selected-profile preflight, project default binding, and Agent Console per-run override controls for EvoPilot v1.1.8.

## What Changed

- Updated the mobile Agent Console blocker visual baseline to include the production `LLM Profiles` navigation item.
- Kept the LLM Profiles page, compact registration modal, provider presets, profile preflight, project default binding, and per-run override controls from v1.0.13.

## Compatibility

- Compatible EvoPilot API: `v1.1.8` or later.
- Dashboard image: `ghcr.io/yeliang-wang/evopilot-dashboard:1.0.14`.
- Node.js: 22 or later for repository validation and local development.
- Docker Compose: v2 for generated container run directories.

## Deploy Paths

Run from the release tag:

```bash
curl -fsSL https://raw.githubusercontent.com/yeliang-wang/evopilot-dashboard/v1.0.14/install.sh | bash -s -- --api-url http://127.0.0.1:19876 --dir evopilot-dashboard-run
```

Deploy the image on a cloud container service:

```bash
gcloud run deploy evopilot-dashboard \
  --image ghcr.io/yeliang-wang/evopilot-dashboard:1.0.14 \
  --port 8080 \
  --set-env-vars EVOPILOT_API_BASE_URL=https://evopilot.example.com
```

## Operator Notes

Use v1.0.14 as the production Dashboard release for the EvoPilot v1.1.8 LLM profile workflow. v1.0.13 carried the same product behavior, but v1.0.14 is the release that closes the mobile visual-regression baseline after `LLM Profiles` became part of the left navigation.
